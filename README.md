## 📌 Di cosa mi occupo

- 🖥️ **Virtualizzazione & Storage:** Gestione ambienti Proxmox VE, container Docker e storage di rete (TrueNAS/OMV).
- 🏠 **Home Automation:** Configurazione avanzata di Home Assistant, integrazioni AppDaemon, script Jinja2 e sensori dedicati.
- 🌐 **Networking & Data Security:** Segmentazione VLAN, gestione DNS/Pi-hole, regole di firewall personalizzate e monitoraggio di rete.
